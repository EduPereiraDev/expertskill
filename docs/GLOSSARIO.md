# 📖 GLOSSÁRIO - Expert Skills

> **Termos e conceitos do domínio de eSoccer e apostas**

---

## 🎮 Termos de eSoccer

### Ligas/Grades

| Termo | Descrição |
|-------|-----------|
| **GT 12min** | Grade principal de 12 minutos (6min HT + 6min FT). Foco do Expert Skills. |
| **Volta 6min** | Grade de 6 minutos sem saída/lateral. Apenas futsal. |
| **H2H** | Head-to-Head. Grade sem auxílio de IA no jogo. |
| **GT 8min** | Grade de 8 minutos. Muito inconsistente, não recomendada. |

### Tempos de Jogo

| Termo | Descrição |
|-------|-----------|
| **HT** | Half Time (Primeiro Tempo) |
| **FT** | Full Time (Tempo Total/Final) |
| **Pré-live** | Antes do jogo começar |
| **Ao vivo** | Durante o jogo |

### Mercados de Apostas

| Termo | Descrição |
|-------|-----------|
| **Over X.5** | Mais de X gols na partida (ex: Over 2.5 = 3+ gols) |
| **Under X.5** | Menos de X gols na partida |
| **Ambas** | Ambos os times marcam (sim/não) |
| **Handicap** | Vantagem/desvantagem de gols para um time |
| **Resultado Correto** | Placar exato da partida |
| **0x0** | Partida sem gols |

## 💰 Termos de Gestão de Banca

| Termo | Descrição |
|-------|-----------|
| **Banca** | Capital total disponível para apostas |
| **Stake** | Valor de cada aposta individual |
| **Meta** | Objetivo de lucro (diário, semanal, etc.) |
| **Gestão Agressiva** | Divide banca por 10 (10 entradas) |
| **Gestão Conservadora** | Divide banca por 20 (20 entradas) |
| **ROI** | Return on Investment (retorno sobre investimento) |
| **Green** | Aposta ganha |
| **Red** | Aposta perdida |
| **Odd** | Cotação/probabilidade da aposta |

---

## 📊 Termos de Análise

| Termo | Descrição |
|-------|-----------|
| **Radar** | Sistema de classificação de jogos em tempo real |
| **Termômetro** | Indicador visual de qualidade do jogo |
| **Cenário 1** | Jogo fraco - evitar over |
| **Cenário 2** | Over segurando - cautela, entrada tardia |
| **Cenário 3** | Melhor jogo - operar com confiança |
| **Confronto H2H** | Histórico de partidas entre dois jogadores |
| **Média de gols** | Quantidade média de gols por partida |
| **Tendência Over** | Percentual de jogos com mais de 2.5 gols |
| **Gols tardios** | Gols que saem no final do jogo |
